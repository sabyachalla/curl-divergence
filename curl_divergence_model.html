Place a paddle wheel near the center, then far from it. Do you expect it to spin faster near the center or near the edge? Write your prediction before trying it.
It spins at the same rate everywhere. The arrows near the edge are longer — the fluid moves faster there — but curl measures the differential rotation across a tiny region, not the speed. Since F = (−y, x) has uniform curl = 2, a paddle wheel spins identically anywhere in the field. Curl is local and constant here.
field
F = (−y, x, 0)
curl computation
curl F = ∇ × F
 = (∂Q/∂x − ∂P/∂y) k̂
 = (∂(x)/∂x − ∂(−y)/∂y) k̂
 = (1 − (−1)) k̂
= 2 k̂ — constant everywhere
divergence
div F = ∂(−y)/∂x + ∂(x)/∂y
 = 0 + 0
= 0 — no expansion or compression

All arrows point to the right. Nothing is visibly spinning or curving. Does this field have nonzero curl? If so, in which direction does the paddle wheel spin?
Yes — curl ≠ 0. The arrows at the top (large y) are long; at the bottom (y near 0) they're short. A paddle wheel's top blade is pushed right harder than its bottom — it spins clockwise. Curl = −k̂. This is the key counterintuition: curl is not about curved arrows. It's about velocity differences across a local region. ∂P/∂y captures exactly this — how much does the horizontal speed change as you move vertically?
field

 = (0 − 1) k̂
= −k̂ — clockwise, everywhere

 = 0 + 0
= 0 — incompressible flow

Set α to max, β to zero. Then reverse. Then find settings where curl = div. What does the field look like in each case? Can you make a field that expands but doesn't rotate?
α only (β=0): pure rotation — the field swirls without expanding. Paddle wheels spin; no flux crosses any box.

β only (α=0): pure expansion — arrows radiate outward, no rotation. Paddle wheels don't spin; boxes show positive flux.

Both: spiraling outward — like a growing vortex.

This is the Helmholtz decomposition: any smooth vector field splits into an irrotational part (curl=0, comes from a gradient ∇φ) and a solenoidal part (div=0, comes from a curl ∇×A). Curl and divergence measure these two independent geometric properties.
field
F = (βx − αy, αx + βy, 0)
curl (live)
curl F = (∂(αx+βy)/∂x − ∂(βx−αy)/∂y) k̂
 = (α − (−α)) k̂ = 2α k̂
= 2.0 k̂
divergence (live)
div F = ∂(βx−αy)/∂x + ∂(αx+βy)/∂y
 = β + β = 2β
= 2.0

This field looks like the whirlpool but has almost no local rotation. The difference: Scene 01 was rigid-body rotation (like a spinning disk — every part rotates at the same rate). This is a free vortex — like water far from a drain. The fluid moves in circles but doesn't spin locally. Curl captures that distinction exactly.
field
F = (−y, x) / (x²+y²)
= (−y/(r²), x/(r²), 0)
where r² = x²+y²
curl (away from origin)
curl F = ∂(x/r²)/∂x − ∂(−y/r²)/∂y
 = (r²−2x²)/r⁴ + (r²−2y²)/r⁴
 = (2r²−2r²)/r⁴
= 0 everywhere (except origin)
the catch — Stokes' theorem
∮ F·dr around origin = 2π ≠ 0
even though curl F = 0!
